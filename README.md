# Fuel Consumption Prediction 🚗

## Overview
This project predicts fuel consumption of heavy vehicles using Machine Learning.

## Features
- Data preprocessing and cleaning
- Exploratory Data Analysis (EDA)
- SVM Regression model
- 89% accuracy achieved

## Tech Stack
- Python
- Pandas, NumPy
- Scikit-learn
- Matplotlib

## Output
Provides predicted fuel consumption based on input parameters.
